## Слайд 2. Почему наш проект нужен TON?
- Не делаем акцент на прозрачности (это уже стандарт у всех фондов)
- Фокус: вовлечение комьюнити, новые механики мотивации, инновации, социальный эффект, масштабируемость
- Примеры:
  - "Мы создаём платформу, где каждый пользователь становится активным участником изменений, а не просто донором."
  - "Вовлекаем пользователей TON в реальные социальные проекты через геймификацию и DAO-голосование."
  - "Интеграция с TON-экосистемой открывает новые возможности для масштабирования и коллабораций."
  - "Наша модель — это не просто сбор средств, а создание устойчивого сообщества вокруг помощи животным."
